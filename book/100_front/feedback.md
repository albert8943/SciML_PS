# Feedback

Help improve these notes: typos, broken links, unclear explanations, and accessibility issues.

## Interim channel (active now)

Open a GitHub issue on the SciML_PS repository with:

- The page **title** and browser URL (copy from the address bar)
- What is wrong or unclear
- Optional suggested fix

## Planned Google Form

A Google Form (EECS 245–style) will replace the interim GitHub channel once a form URL is ready.

Do not paste confidential research data or student grades into public issues.

## Accessibility

We aim for **WCAG 2.1 AA** so readers can use the notes with assistive technology and without relying on colour alone. If something blocks access — missing figure alt text, low contrast, an uncaptioned video or plot, or a keyboard trap — report it through the GitHub channel above (page title, URL, and what you hit).

Authors: every figure needs an `:alt:` description; every important plot needs a short text caption; do not encode meaning only in colour. Checklist: `book/chapter_template.md`.
