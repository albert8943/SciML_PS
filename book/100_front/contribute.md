# Join and contribute

These notes are a **collaborative teaching resource** under active development. Experts in power-system dynamics, stability, scientific machine learning, and system identification — and careful students — are welcome to help over the long term.

:::{note} Under development (v0.x)
Until the first stable edition (**v1.0**), treat the book as a public preview: structure and goals are intentional; many pages are still thickening. See [Status and versions](status_and_versions.md).
:::

## Cross-domain collaboration

This book is a bridge. A chapter is stronger when a machine-learning reader and a power-systems reader both review it.

| Contribution | Why it helps |
|--------------|--------------|
| A [glossary](../990_reference/glossary.md) row that translates one term into the other field | Gives the next reader a shared word |
| A "Coming from ML" or "Coming from power systems" sentence on a chapter you know | Lets people jump in without reading everything above |
| A paired review (one reader from each field) on a pull request | Catches jargon that only one community understands |
| A teacher overlay (week plan) for [Learning paths](learning_paths.md#path-teachers) | Lets another course reuse the same labs |

A glossary row or a translation sentence is a good first contribution. A single row is enough.

## What we ask

1. Use **published** sources only — no sealed research metrics on student pages.  
2. Write in teaching voice; cite neighbors honestly ([Related open resources](related_resources.md)).  
3. Sign every commit (`git commit -s`) so contributions come in under the same licences as the book (content CC BY-NC-SA 4.0, code MIT).  
4. Keep the three applications — dynamics, stability, identification — as the core unless a governance discussion says otherwise.

## Interest in a longer role

Open a GitHub issue with the **Collaboration / section editor** template, or start a Discussion in the Collaborators category once Discussions are enabled. We expect to appoint section editors gradually as the preview matures.
