# Scientific Machine Learning for Power Systems

Welcome. This book teaches scientific machine learning (SciML) methods organized around three power-system questions:

1. **Dynamics** — How will the system evolve under specified inputs, parameters, and disturbances?
2. **Stability** — Will the system remain stable, and how close is it to a stability boundary?
3. **Identification** — Which parameters and dynamic relationships explain the measurements?
